How to read these numbers

The unit is the visitor-day: one browser on one network on one day. Pinakes gives each visitor an id that changes every day and cannot be traced back to an address, so nobody can be followed from one day to the next, and someone who returns on three days counts three times.

People are counted in two groups. Browser-confirmed visitor-days ran the page's script, which crawlers almost never do. Likely visitor-days used an ordinary browser on an ordinary network but never ran it, usually because JavaScript was blocked. Bots, scripts, feed readers and traffic from hosting companies are counted separately and appear only in the last section.

Institutions are identified from the network a visit came from, using the address registries, reverse DNS, IPEDS, ROR and the world-universities list. Only on-campus connections can be identified. Faculty and students reading from home or a phone show up as their internet provider, so the institution count is a minimum, not a census. Raw IP addresses are deleted within {{ s.data.raw_ip_hours }} hours of the visit.
